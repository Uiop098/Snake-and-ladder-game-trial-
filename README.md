# 🎲 Snakes & Ladders Web Game

An interactive, animated, browser-based recreation of the classic **Snakes and Ladders** board game built with HTML5, CSS3, and JavaScript.

## 🕹️ Gameplay & Features

- **👥 Multi-Player Support:** Play with 1 to 4 local human players or solo against Computer Bot AI.
- **🎨 Player Customization:** Select custom emojis, avatars, and neon token colors for each player.
- **🎲 Physics Dice Roller:** Interactive 3D animated dice with single or double dice modes.
- **🐍 Snakes & 🪜 Ladders:** Authentic board mechanics with animated token sliding and climbing.
- **🔊 Sound & Haptic Feedback:** Audio effects for dice rolls, climbing ladders, snake bites, and mobile haptic vibration.
- **📱 Fully Responsive:** Optimized for desktop browsers, tablets, and mobile touchscreen viewports.

## 📜 Rules of the Game

1. Players start outside the board and take turns rolling the dice.
2. Tokens advance by the exact number shown on the dice.
3. **Ladders:** Landing on the base of a ladder advances your token to the top square.
4. **Snakes:** Landing on a snake's head sends your token sliding down to its tail.
5. The first player to reach square **100** wins the match!
